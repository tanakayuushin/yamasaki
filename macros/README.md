# Excel マクロ：同じ企業を1行に集約

`ConsolidateCompanies.bas` は、工種ごとに企業名を入力した一覧表で
複数行に点在している同じ企業を 1 行にまとめ、工種を結合するマクロです。

## 動作イメージ

| 企業名 | 工種 | 担当者 |
|---|---|---|
| 山口建設 | 土木 | 佐藤 |
| 周南電業 | 電気 | 鈴木 |
| 山口建設 | 舗装 | |
| 山口建設 | 電気 | |

↓ 実行後（「集約結果」シート）

| 企業名 | 工種 | 担当者 | 元の行数 |
|---|---|---|---|
| 山口建設 | 土木、舗装、電気 | 佐藤 | 3 |
| 周南電業 | 電気 | 鈴木 | 1 |

- 元のシートは一切変更しません。結果は別シート（既定名「集約結果」）に出力します。
- 企業名・工種以外の列は、最初に出てきた行の値を使い、空欄なら後の行の値で補います。
- 企業名の比較では全角・半角スペースの有無や英数カナの全角・半角の違いを無視します。
  （「株式会社」と「（株）」は別企業として扱われます）

## 導入手順

1. 対象の Excel ブックを開き、`Alt + F11` で VBE を開く
2. メニュー「ファイル」→「ファイルのインポート」で `ConsolidateCompanies.bas` を選ぶ
   （または「挿入」→「標準モジュール」を追加して本文を貼り付ける）
3. モジュール先頭の **設定** を自分の表に合わせて書き換える
4. 集約したいシートを表示した状態で `Alt + F8` →「企業を1行に集約」を実行
5. マクロを残す場合はブックを `.xlsm` 形式で保存する

## 設定項目（モジュール先頭）

| 定数 | 既定値 | 説明 |
|---|---|---|
| `HEADER_ROW` | `1` | 見出し行の行番号 |
| `COMPANY_COL` | `"企業名"` | 企業名の列。見出し文字列か列記号（`"B"` など） |
| `WORKTYPE_COL` | `"工種"` | 工種の列。見出し文字列か列記号 |
| `DELIMITER` | `"、"` | 工種をつなぐ区切り文字（`"/"`、`vbLf` なども可） |
| `OUTPUT_SHEET` | `"集約結果"` | 結果シート名 |
| `DEDUPE_WORKTYPES` | `True` | 同じ工種が重複したら 1 回だけ表示 |
| `NORMALIZE_COMPANY_NAME` | `True` | 企業名の表記ゆれ（スペース・全半角）を吸収 |
| `ADD_COUNT_COLUMN` | `True` | 末尾に「元の行数」列を付ける |
