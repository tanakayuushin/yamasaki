# Excel マクロ：同じ業者を1行に集約

`ConsolidateCompanies.bas` は、「依頼リスト」シートに工種ごとに入力した業者を、
業者ごとに 1 行へまとめて「Sheet1」に書き出すマクロです。ボタン（マクロ）は 2 つあります。

| ボタン | まとめ方 |
|---|---|
| **業者を1行に集約** | 業者ごとに 1 行。担当者やメールアドレスが違っても同じ業者なら 1 行にし、最初に出てきた行の値を採用（空欄なら後の行で補う） |
| **業者と担当者ごとに集約** | 業者と担当者の組み合わせごとに 1 行。同じ業者でも担当者が違えば別の行になる（担当者が空欄の行は「担当者なし」のグループとして 1 行）。同じ業者の行は連続して並び、業者名の表記は最初に出てきた行のものにそろえる |

結果の並び順は、どちらも業者の初出順です。

## シート構成

| シート | 役割 |
|---|---|
| **依頼リスト** | 入力用。依頼する業者・工種などを 1 行ずつ書く（同じ業者が何行あってもよい） |
| **Sheet1** | 出力用。ボタンを押すと見出し行より下が消され、業者ごとに 1 行にまとめた結果が書かれる |

どちらも見出しは 2 行目、A 列は余白、列は次のとおりです（Sheet1 は見出しの文字で列を対応づけるので、列の順番が違っても構いません）。

| B | C | D | E | F | G | H | I | J | K | L | M |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 工種 | 業者 | 担当者 | メールアドレス | 依頼 | 返答 | 見積書 | お礼 | 見積入力 | 経過連絡 | 備考 | NET金額（合計） |

## 動作イメージ

依頼リスト

| 工種 | 業者 | 担当者 | 備考 | NET金額（合計） |
|---|---|---|---|---|
| 土木 | 山口建設 | 佐藤 | 現調済 | 1,000,000 |
| 電気 | 周南電業 | 鈴木 | | 300,000 |
| 舗装 | 山口建設 | | | 500,000 |
| 電気 | 山口建設 | | 追加見積あり | 200,000 |

↓ ボタンを押すと Sheet1 に

| 工種 | 業者 | 担当者 | 備考 | NET金額（合計） |
|---|---|---|---|---|
| 土木、舗装、電気 | 山口建設 | 佐藤 | 現調済 ／ 追加見積あり | 1,000,000<br>500,000<br>200,000<br>合計：1,700,000 |
| 電気 | 周南電業 | 鈴木 | | 300,000 |

- 「依頼リスト」は変更しません。「Sheet1」は見出し行より下の値だけを書き直し、罫線・塗り・列幅などの書式は残します。Sheet1 が無ければ「依頼リスト」を複製して作ります。
- **工種** は「、」で結合します（同じ工種は 1 回だけ）。
- **NET金額（合計）** は業者ごとの金額として、項目ごとに 1 行ずつセル内に並べ、最後に「合計：金額」を付けます（工種名は付けません）。
  - 項目名付きの書き方（例「基礎工事 800,000／外構 450,000」「外壁：120,000、屋根：78,000」）は「項目名：金額」
  - 数値だけのセルは金額だけの行
  - 「150,000円」「￥450,000」「１，２５０，０００」のような書き方も金額として読み取ります。「10/25」のような日付は金額にしません
  - 業者の金額が 1 件だけなら、その値をそのまま（数値・表示形式も元どおり）
- **備考** は「 ／ 」で結合します（同じ文言は 1 回だけ）。
- それ以外の列（担当者、メールアドレス、依頼〜経過連絡）は最初に出てきた行の値を使い、空欄なら後の行の値で補います。
- 業者名の比較では全角・半角スペースや英数カナの全半角の違いを無視します。
  （「株式会社」と「（株）」は別業者として扱われます）

## すぐ使う場合（マクロ組み込み済みブック）

`業者集約マクロ付き.xlsm` は、送っていただいたブックを「依頼リスト」「Sheet1」の 2 シート構成にして、このマクロを組み込んだものです。
動きを試したいときは、12 行のサンプル（4 社。山口建設と周南電業は担当者が 2 人ずつ）を依頼リストに入れた `業者集約マクロ付き_サンプルデータ入り.xlsm`、
件数が多い場合の確認には 60 工種・20 社を入れた `業者集約マクロ付き_サンプルデータ工種50以上.xlsm` を使ってください。
マクロなしのサンプルデータは `サンプルデータ.xlsx`・`サンプルデータ_工種50以上.xlsx` です。

1. ファイルをダウンロードし、右クリック →「プロパティ」→「許可する」にチェックして OK（ブロック解除）
2. 開いて、黄色い帯の「コンテンツの有効化」を押す
3. 「依頼リスト」に入力し、表の右側（O2 付近）にある青いボタン **「業者を1行に集約」** または **「業者と担当者ごとに集約」** をクリック
   （どちらのシートのボタンでも、`Alt + F8` からでも実行できます）
4. 結果は「Sheet1」に出ます。依頼リストを直したら何回でも押し直せます（Sheet1 は毎回書き直されます）

## 自分のブックに組み込む場合

> **日本語版 Excel の VBE に取り込むときは `ConsolidateCompanies_ShiftJIS.bas` を使ってください。**
> `ConsolidateCompanies.bas` は UTF-8（GitHub 上で読みやすい形）で、そのままインポートすると日本語が文字化けして
> コンパイルエラーになります。`_ShiftJIS.bas` は同じ内容を Shift-JIS・CRLF で保存したものです。

1. 対象の Excel ブックを開き、`Alt + F11` で VBE を開く
2. メニュー「ファイル」→「ファイルのインポート」で `ConsolidateCompanies.bas` を選ぶ
   （または「挿入」→「標準モジュール」を追加して本文を貼り付ける）
3. 必要ならモジュール先頭の **設定** を書き換える
4. 集約したいシートを表示した状態で `Alt + F8` →「業者を1行に集約」を実行
5. マクロを残す場合はブックを `.xlsm` 形式で保存する

## 設定項目（モジュール先頭）

| 定数 | 既定値 | 説明 |
|---|---|---|
| `INPUT_SHEET` | `"依頼リスト"` | 入力用シート名 |
| `OUTPUT_SHEET` | `"Sheet1"` | 出力用シート名（無ければ依頼リストを複製して作る） |
| `HEADER_ROW` | `2` | 見出し行の行番号（両シート共通） |
| `COMPANY_COL` | `"業者"` | 業者名の列。見出し文字列か列記号（`"C"` など） |
| `WORKTYPE_COL` | `"工種"` | 工種の列。見出し文字列か列記号 |
| `DELIMITER` | `"、"` | 工種をつなぐ区切り文字（セル内改行は `vbLf`） |
| `BREAKDOWN_COLS` | `"NET金額（合計）"` | 項目ごとの内訳として並べる列（カンマ区切りで複数可） |
| `BREAKDOWN_NUMFMT` | `"#,##0"` | 内訳の金額の表示形式 |
| `BREAKDOWN_SHOW_EMPTY` | `False` | 金額が未入力の行も「未入力」として内訳に載せる |
| `SUM_COLS` | `""` | 内訳ではなく単純に合計したい列（カンマ区切りで複数可） |
| `JOIN_COLS` | `"備考"` | 文字列を結合する列（カンマ区切りで複数可） |
| `JOIN_DELIMITER` | `" ／ "` | 結合する列の区切り文字 |
| `DEDUPE_WORKTYPES` | `True` | 同じ工種が重複したら 1 回だけ表示 |
| `NORMALIZE_COMPANY_NAME` | `True` | 業者名の表記ゆれ（スペース・全半角）を吸収 |
| `ADD_COUNT_COLUMN` | `False` | 末尾に「元の行数」列を付ける（表の形が 1 列増える） |
| `WRAP_WORKTYPE` | `True` | 結合した工種が列幅に収まらないときセル内で折り返す（列幅は変えない） |
| `SPLIT_KEY_COLS` | `"担当者"` | 「業者と担当者ごとに集約」で、業者に加えて行を分ける基準にする列（カンマ区切りで複数可。例 `"担当者,メールアドレス"`） |

## 開発者向け：.xlsm の再生成

`tools/add_sheet_copy.py` で 1 シートのブックを「依頼リスト」「Sheet1」の 2 シート構成にし、
`tools/build_xlsm.py` でマクロと実行ボタンを組み込みます（Excel 不要、Python 3 標準ライブラリのみ）。

```bash
python3 macros/tools/add_sheet_copy.py 元ブック.xlsx 2シート版.xlsx Sheet1 依頼リスト 0 --clear-data 2
python3 macros/tools/build_xlsm.py 2シート版.xlsx macros/ConsolidateCompanies.bas macros/業者集約マクロ付き.xlsm "業者を1行に集約;業者と担当者ごとに集約" "業者を1行に集約;業者と担当者ごとに集約"
```

自分のブックにボタンを付けたい場合は、Excel で「挿入」→「図形」で四角形を置き、
右クリック →「マクロの登録」→「業者を1行に集約」を選べば同じものになります。
