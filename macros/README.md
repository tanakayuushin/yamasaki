# Excel マクロ：同じ業者を1行に集約

`ConsolidateCompanies.bas` は、工種ごとに業者を入力した見積依頼一覧で
複数行に点在している同じ業者を 1 行にまとめ、工種を結合するマクロです。

対象ブックの表（見出し 2 行目、A 列は余白）に合わせて既定値を設定済みです。

| B | C | D | E | F | G | H | I | J | K | L | M |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 工種 | 業者 | 担当者 | メールアドレス | 依頼 | 返答 | 見積書 | お礼 | 見積入力 | 経過連絡 | 備考 | NET金額（合計） |

## 動作イメージ

| 工種 | 業者 | 担当者 | 備考 | NET金額（合計） |
|---|---|---|---|---|
| 土木 | 山口建設 | 佐藤 | 現調済 | 1,000,000 |
| 電気 | 周南電業 | 鈴木 | | 300,000 |
| 舗装 | 山口建設 | | | 500,000 |
| 電気 | 山口建設 | | 追加見積あり | 200,000 |

↓ 実行後（「集約結果」シート）

| 工種 | 業者 | 担当者 | 備考 | NET金額（合計） |
|---|---|---|---|---|
| 土木、舗装、電気 | 山口建設 | 佐藤 | 現調済 ／ 追加見積あり | 1,700,000 |
| 電気 | 周南電業 | 鈴木 | | 300,000 |

- 元のシートは変更しません。元シートをそのまま複製した「集約結果」シートに書き出すので、罫線・塗り・列幅・行の高さ・表示形式・印刷設定は元と同じです。
- **工種** は「、」で結合します（同じ工種は 1 回だけ）。
- **NET金額（合計）** は業者ごとに合計します。
- **備考** は「 ／ 」で結合します（同じ文言は 1 回だけ）。
- それ以外の列（担当者、メールアドレス、依頼〜経過連絡）は最初に出てきた行の値を使い、空欄なら後の行の値で補います。
- 業者名の比較では全角・半角スペースや英数カナの全半角の違いを無視します。
  （「株式会社」と「（株）」は別業者として扱われます）

## すぐ使う場合（マクロ組み込み済みブック）

`業者集約マクロ付き.xlsm` は、送っていただいたブックにこのマクロを組み込んだものです。
シートの内容・書式はそのままで、マクロだけが追加されています。
動きを試したいときは、10 行のサンプルデータを入れた `業者集約マクロ付き_サンプルデータ入り.xlsm` を使ってください。

1. `業者集約マクロ付き.xlsm` をダウンロードして開く
2. 黄色い帯の「コンテンツの有効化」を押す
3. 表の右側（O2 付近）にある青いボタン **「業者を1行に集約」** をクリック
   （`Alt + F8` →「業者を1行に集約」でも実行できます）

ダウンロードしたファイルがブロックされてマクロが動かないときは、
ファイルを右クリック →「プロパティ」→「許可する」にチェックして OK を押してから開いてください。

## 自分のブックに組み込む場合

1. 対象の Excel ブックを開き、`Alt + F11` で VBE を開く
2. メニュー「ファイル」→「ファイルのインポート」で `ConsolidateCompanies.bas` を選ぶ
   （または「挿入」→「標準モジュール」を追加して本文を貼り付ける）
3. 必要ならモジュール先頭の **設定** を書き換える
4. 集約したいシートを表示した状態で `Alt + F8` →「業者を1行に集約」を実行
5. マクロを残す場合はブックを `.xlsm` 形式で保存する

## 設定項目（モジュール先頭）

| 定数 | 既定値 | 説明 |
|---|---|---|
| `HEADER_ROW` | `2` | 見出し行の行番号 |
| `COMPANY_COL` | `"業者"` | 業者名の列。見出し文字列か列記号（`"C"` など） |
| `WORKTYPE_COL` | `"工種"` | 工種の列。見出し文字列か列記号 |
| `DELIMITER` | `"、"` | 工種をつなぐ区切り文字（セル内改行は `vbLf`） |
| `SUM_COLS` | `"NET金額（合計）"` | 数値を合計する列（カンマ区切りで複数可） |
| `JOIN_COLS` | `"備考"` | 文字列を結合する列（カンマ区切りで複数可） |
| `JOIN_DELIMITER` | `" ／ "` | 結合する列の区切り文字 |
| `OUTPUT_SHEET` | `"集約結果"` | 結果シート名 |
| `DEDUPE_WORKTYPES` | `True` | 同じ工種が重複したら 1 回だけ表示 |
| `NORMALIZE_COMPANY_NAME` | `True` | 業者名の表記ゆれ（スペース・全半角）を吸収 |
| `ADD_COUNT_COLUMN` | `False` | 末尾に「元の行数」列を付ける（表の形が 1 列増える） |
| `WRAP_WORKTYPE` | `True` | 結合した工種が列幅に収まらないときセル内で折り返す（列幅は変えない） |

## 開発者向け：.xlsm の再生成

`tools/build_xlsm.py` は、元の .xlsx にこのモジュールを組み込んだ .xlsm を Excel なしで生成します
（Python 3 標準ライブラリのみ）。マクロを修正したあとは次のように再生成できます。

```bash
python3 macros/tools/build_xlsm.py 元ブック.xlsx macros/ConsolidateCompanies.bas macros/業者集約マクロ付き.xlsm 業者を1行に集約 "業者を1行に集約"
```

最後の 2 つ（実行する Sub 名、ボタンの文字）を付けると、先頭シートにクリックで実行できる図形ボタンも置きます。
自分のブックにボタンを付けたい場合は、Excel で「挿入」→「図形」で四角形を置き、
右クリック →「マクロの登録」→「業者を1行に集約」を選べば同じものになります。
